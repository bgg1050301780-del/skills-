# Skill Studio — 可视化 Skill 创作器

简体中文 Windows 桌面软件，用来创建、研究、编辑和导出 AI Agent Skill。支持离线编辑；只有主动使用 AI 时才连接用户配置的模型服务。软件不会执行 Skill 中的剪辑、生成视频或脚本任务。

## 普通用户怎么使用

1. 运行交付目录中的免安装程序，或使用安装包安装后打开桌面快捷方式。
2. 左侧选择“新建 Skill 项目”，填写名称、标识符、描述与用途。
3. 依次填写触发条件、输入材料、工作流程、异常处理和完成标准。标识符使用小写英文字母、数字和短横线，例如 `smart-video-edit`。
4. 在工作流程中添加步骤。每个字段可以单独编辑，支持复制、删除、拖动排序和上移下移。
5. “工具调用”与步骤中的工具共用数据。确认接口、权限和运行环境确实可用后，才能勾选“已验证”。
6. 底部上传参考资料，在步骤中勾选关联。资料默认只保存在本机；在“参考资料”栏目中明确允许后，AI 才能读取支持的文本资料。
7. 点击“设置”，填写模型地址、密钥和模型名称，保存并测试。造梦鲸的地址和协议按用户提供的文档接入；其他服务须兼容 Responses 协议、结构化输出和流式事件。
8. 向右侧助手提出修改要求。先看说明与前后差异，点击“应用修改”才会改变项目。取消方案不改变项目；应用后可以撤销或恢复历史版本。
9. 查看 SKILL.md 和项目结构预览，在“导出设置”中检查问题，导出标准 Skill、设计需求包或项目备份。

所有编辑自动保存；`Ctrl+S` 可立即保存。关闭后再次打开会恢复最近打开的项目。删除项目会移入本机应用数据的回收目录，原始导入文件不受影响。

## 导入与资料

- 支持单个 `SKILL.md`、完整 Skill 文件夹和 ZIP。
- 已识别内容填入表单；无法确定的内容保留在原始内容中，需要用户确认的事项进入导出检查。
- 原始 SKILL.md 随项目数据保留；没有编辑时优先原样导出。导入的脚本、素材和其他文件按字节保存，不执行脚本。
- 导出包中的 `.skill-studio/project.json` 用于重新导入后恢复表单、步骤固定编号、资料关联、未知原文等编辑信息。它不包含模型密钥或聊天会话。
- 空目录不生成。导出到文件夹时自动创建新目录，不覆盖已有目录。
- ZIP 最大 128 MB；单文件最大 64 MB；解压内容合计最大 256 MB、最多 2000 项。文件夹导入采用相同的单文件与总量限制。拒绝路径穿越、符号链接、Windows 特殊名称和大小写冲突。
- 第一版 AI 资料读取支持不超过 100 KB 的 Markdown、TXT、JSON、CSV 和 YAML。图片、音频、视频、PDF 和脚本作为本地资料管理；未实现这些二进制附件的自动理解。

## 模型、安全与费用

- AI 核心是官方 `@openai/codex-sdk`，由 Electron 后台调用，版本锁定在依赖文件中。界面进程无 Node.js 权限，通过受限消息接口请求本地操作。
- 每个项目单独保存 Codex 会话编号与聊天记录。每次请求重新附带当前项目状态，撤销内容后不会把旧聊天当作当前项目。
- 自定义接口的真实密钥由 Windows 安全存储加密；Codex 子进程只收到受控本机接口的一次性访问码。项目、导出包和公共日志不写入真实密钥。
- 自定义接口经本机受控转发，只允许模型 Responses 请求，移除文件、联网和脚本工具；禁用命令工具，并使用只读权限。任何模型方案都需通过字段白名单、步骤编号和项目版本校验。
- 官方登录使用独立的本地 Codex 配置目录和系统凭据存储，不修改电脑上其他 Codex 应用的登录资料。
- 本次真实验收获用户授权上限 5 元。测试通过价格接口取得账号实付价格上界，按输入字节和输出上限保守预留；在接口费用回执不可用时不释放预留，避免反复重试超预算。预算文件不随源码发布。
- 自定义非造梦鲸服务无法自动取得人民币价格；请根据该服务账单核对费用。

## 开发与构建

需要 Windows x64、Node.js 24 和 npm。安装依赖后：

```powershell
npm ci
npm run dev
npm test
npm run build
npm run test:desktop
npm run dist
```

`dev` 启动界面开发服务和桌面窗口；`build` 检查 TypeScript 并生成正式界面；`test` 测试数据、解析、导出与安全边界；`test:desktop` 在隔离数据目录中通过真实桌面界面测试；`dist` 生成免安装版和安装包。真实 AI 验收额外设置 `STUDIO_LIVE_TEST=1`，仅可在已获授权且配置可用的密钥时运行。

首次下载 Electron 运行组件时，如果官方下载地址网络不可达，可在当前 PowerShell 窗口设置 `ELECTRON_MIRROR` 为可信镜像后重新安装，仍执行包内校验和验证。本项目不跳过下载完整性校验。

## 目录说明

| 目录 | 内容 |
|---|---|
| `src/` | React 中文界面与样式 |
| `shared/core.mjs` | 统一项目结构、Skill 解析生成、方案验证及 ZIP 防护 |
| `electron/store.mjs` | 本地保存、附件内容校验、版本恢复、导入导出 |
| `electron/ai.mjs` | Codex SDK、模型配置、安全存储、受控调用与费用保护 |
| `electron/main.mjs` | 桌面窗口、受限操作接口和原生文件选择 |
| `tests/` | 可重复运行的核心和桌面验收 |
| `examples/` | 智能剪辑示例及不同结构的导入样本 |
| `evidence/` | 无密钥的测试记录和界面截图 |
| `release/` | 本机生成的交付程序，不提交进源码仓库 |

## 数据与回退

项目数据保存在 Windows 用户的应用数据目录，点击“使用教程 → 打开本机数据目录”可以查看。项目之间独立保存；附件按内容校验值存放，历史版本不会因删除当前附件而失效。保存先写临时文件并落盘，再替换正式文件；保留上一份有效备份。

软件内历史版本用于恢复 Skill 内容。软件发布版本通过 Git 提交及唯一版本标签存档，GitHub 保存源码和标签；回退程序版本前建议先导出项目备份。
